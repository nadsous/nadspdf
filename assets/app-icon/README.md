# NadsPDF app icon

The nads.site mark (the stepped "N") in red `#EF3E36`, with "PDF" in blocky lettering below that
echoes the mark's notches, on a `#111113` rounded tile (`rx = 224` on a 1024 canvas). No font is
involved: every shape is a right-angled polygon.

Every file here is generated by `python packaging/nads_icons.py` (Pillow), from the geometry in
that script. File names are upstream PdfCraft's so every reference keeps working.

| File | What it is |
|---|---|
| `pdfcraft.svg`, `pdfcraft-small.svg` | master vector (tile) |
| `nadspdf-mark.svg` | the logo without tile (home screen, About) |
| `nads-n.svg` | the red mark alone (title bar) |
| `pdfcraft-1024.png`, `pdfcraft.icns` | macOS (824 px body on a 1024 canvas) |
| `pdfcraft.ico`, `pdfcraft-document.ico` | Windows, 16–256 px |
| `hicolor/` | Linux hicolor theme, 16–512 px |

Trademark of nads, not covered by the code licence: see `docs/brand/LICENSE-brand.txt`.
After regenerating, run `cargo xtask assets --write` to refresh the hashes.
